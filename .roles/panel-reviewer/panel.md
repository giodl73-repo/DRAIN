# Wastewater Peer Panel (illustrative)

Archetype peer reviewers for DRAIN research outputs — distinct from the parliament (adversarial design review) and the editorial gate (form review). Each is an archetype, not a named person.

| ID | Reviewer archetype | Expertise |
|---|---|---|
| R-P1 | Wastewater system planner | Utility planning, collection/treatment networks, tiered service |
| R-P2 | Hydrologic / network scientist | Sewer topology, wet-weather flow, graph algorithms, resilience |
| R-P3 | Public-health / environmental economist | Benefit-cost, disease avoidance, receiving-water value, rates |
| R-P4 | Wastewater operations researcher | Plant/collection operations, CSO/SSO control, reliability |
| R-P5 | Water-quality / equity scholar | Nutrients, habitat, environmental justice, affordability |

Assignment guide:

- Topology / resilience method → R-P2, R-P4
- Capacity / overflow / operations → R-P4, R-P1
- Public-health economics / affordability → R-P3, R-P5
- Receiving-water / equity / environment → R-P5, R-P1
- Tier/SLA + multi-scale methodology → R-P1, R-P4
