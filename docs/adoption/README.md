# DRAIN Open Adoption Guide

## Purpose

DRAIN is public and open to use as a reference model for evidence-gated
wastewater, collection, conveyance, overflow, treatment, recovery, and
affordability analysis. Its next public milestone is a narrow, source-backed
first cited run.

Public use does not create an engineering study, treatment design,
discharge-permit application, rate-case support, consent-decree determination,
or EPA, state-agency, utility, or operator endorsement.

## First Run Path

Use [`first-public-run-worksheet.md`](first-public-run-worksheet.md) to scope
one utility service area, collection basin, overflow problem, treatment
constraint, receiving-water exposure, or affordability question.

The first run should prove the source-to-corpus-to-gap workflow, not settle a
permit, consent-decree, rate, or engineering case.

## Contribution Targets

- public source inventories for collection, conveyance, treatment, overflow,
  effluent, asset, affordability, or receiving-water evidence;
- source/claim corrections for capacity, wet-weather, permit, or rate language;
- reviewer notes from utility operations, wastewater engineering, environmental
  compliance, affordability, resilience, finance, or public-language lenses.

## Gate

Decision: **open_for_first_public_run_scoping**

Rationale: DRAIN can accept bounded source and review contributions before a
first cited run. Reuse alone does not create engineering, permit, rate-case,
consent-decree, endorsement, or validation claims.
